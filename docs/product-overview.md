# DevPulse Product Overview

## 1. Product Name
DevPulse is a technical monitoring platform for developers and small teams.

## 2. Product Type
DevPulse is a SaaS-style portfolio product focused on website and web application monitoring.

## 3. Problem Statement
- Production JavaScript errors are hard to track manually.
- Users may face issues without reporting them.
- Developers need a simple dashboard to view errors.
- Small projects need lightweight monitoring without complex enterprise tools.

## 4. Target Users
- Frontend developers
- Full-stack developers
- Freelancers
- Small teams
- Portfolio project owners
- Startup MVP builders

## 5. Product Goal
The goal of DevPulse is to help developers quickly detect, store, and review frontend runtime errors from their deployed websites through a simple project-based dashboard.

## 6. Core Monitoring Areas
- JavaScript runtime errors
- Unhandled promise rejections
- Core Web Vitals
- API failures
- Uptime issues

## 7. MVP Summary
- Landing page
- User registration and login
- Dashboard layout
- Create monitoring project
- Generate project key
- Show SDK installation snippet
- Capture JavaScript errors
- Capture unhandled promise rejections
- Store error logs
- View error list and error detail
- Deploy frontend and backend

## 8. What DevPulse Is Not in MVP
- Billing or subscription
- Team management
- Advanced alerting
- Source map support
- Session replay
- AI error explanation
- Core Web Vitals dashboard
- API failure tracking dashboard
- Uptime monitoring

## 9. Portfolio Value
- Full-stack product thinking
- Authentication
- Dashboard architecture
- Manual PostgreSQL queries
- SDK-style browser integration
- Error tracking workflow
- Production deployment
- Real-world developer tooling concept

## 10. Success Criteria
The MVP is successful when a user can register, create a project, copy an SDK snippet, add it to a test website, generate a JavaScript error, and view that error inside the DevPulse dashboard.
